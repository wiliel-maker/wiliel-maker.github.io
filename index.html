Флагман

Браузер внутри Minecraft

Собственный движок · аналог WebDisplays

Полноценный веб-браузер, который отображается прямо на блоке-экране в игре. Готового решения под новую версию не было, поэтому движок написан с нуля: Chromium через JCEF в фоновом режиме, рендер каждого кадра в текстуру блока, живой ввод — клик, клавиатура, прокрутка, адресная строка. Экраны можно собирать в стену из нескольких блоков, а действия синхронизируются между игроками в мультиплеере. Собран в один раздаваемый мод.

Java Fabric Minecraft 26.2 JCEF / Chromium OpenGL Networking
